## Important issues

### 1. Logs page has no document H1

- **Where:** `#/logs`
- **What:** Main logs view renders tabs/filters/table without a page-level `<h1>`.
- **Impact:** Screen reader outline and SEO-style heading audits fail; inconsistent with other pages.
- **Fix:** Add `<header class="page-head"><h1>Logs</h1>…</header>` in `renderLogs()`.

### 2. Users page has no document H1

- **Where:** `#/users`
- **What:** Table and modals use `<h2>` (“Create user”) without a page `<h1>`.
- **Impact:** Skipped-level heading structure; weaker a11y landmark.
- **Fix:** Add page header with `<h1>Users</h1>` above the table.

### 3. Endpoints page has no document H1

- **Where:** `#/endpoints`
- **What:** Content starts at `<h2>Routes</h2>`.
- **Impact:** Same as above.
- **Fix:** Add `<h1>Endpoints</h1>` (or “API reference”) in `renderEndpoints()`.

### 4. Default `armin` login not seeded

- **Where:** `POST /api/login` with workspace default credentials
- **What:** `armin` / `dopadopa123` → **401**; `admin` / `admin` works.
- **Impact:** Local verification against environment default login fails unless user is seeded.
- **Fix:** Seed `armin` user in bootstrap or document that only `admin` exists in Docker volume.

## Minor issues

- Login route does not reset `document.title` after sign-out; stale `Pont · Admin` on `#/login`.
- Providers route needs ~2–4s async load; brief empty `#main` if probed too early (race in automated tests only).
- `/robots.txt` and `/sitemap.xml` serve SPA HTML (nginx fallback) — misleading for crawlers if ever exposed publicly.
- No skip link for main content.
- Public SEO meta (description, Open Graph) absent — acceptable for admin, note if ever public.

## Recommendations

- Run Lighthouse a11y/perf in Chrome against `:9881` before release; target ≥90 a11y.
- Add page H1s on Logs, Users, Endpoints in one small UI pass.
- Set `document.title = 'Pont'` (or “Pont · Sign in”) in `renderLogin()` / logout path.
- If exposing WebUI beyond localhost: add security headers on nginx, real 404 for unknown paths, and fix robots/sitemap.
- Re-test on Firefox and Safari once H1 fixes land.
